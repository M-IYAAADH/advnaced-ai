Definition of Ready

  • Has one owner, story points and a clear acceptance check.
  • Its dependencies are done, or will be done early in the sprint.
  • It names the data issue IDs (from data_issues.md) it addresses.

Definition of Done

  • The acceptance check is met, and another member has reviewed it.
  • Outputs are built by a script into derived/; raw files are untouched.
  • Every record traces to a source file and row. Unknown stays unknown.
  • No invented labels: a road with no report is unknown, not dry. A rainfall amount is never called a threshold.
  • Committed and pushed to GitHub; data_issues.md statuses updated.

Updating this board

Every task lives in sprint.md in the project root. To move a card, change its Status cell to To do, In progress, Review or Done, then commit and push. Teammates pull to see the update.

  1. git pull
  2. Edit your row in sprint.md (keep the table headers, and don't type | inside a cell).
  3. git commit -am "MF-11: In progress", then git push.

Serve the folder (python3 -m http.server 8080) and open http://localhost:8080/sprint_board.html; the board re-reads sprint.md every 15 seconds. If you open the HTML file directly from disk, use Load sprint.md. If an edit breaks the table, the message at the top says which row, and the board keeps showing the last version that loaded correctly.
