# Data acquisition specification for Male flood research

Prepared14November2026. This is a request specification for your group; nothing has been sent to agencies.

## Council / NDMA: observed flood labels

Ask for deidentified records for several independent rainfall events on Male island proper. Suggested fields: event_id; island_code; location_id; observation_time; timezone; coordinates/street segment/grid; location_precision_m; observed_status (flooded/dry/unknown); observation_coverage; flood_mechanism (rainwater/coastal/compound/unknown); evidence_type; verification_status; measured_depth_m and measurement time if available; measured_duration and definition if available; intervention/pumping time if documented. Request dates covered, recording changes, reporting biases, and use/publication terms. A sandbag request is not by itself verified inundation. No report is not a dry label.

Ask the Council for the event register and hazard maps behind the Draft Male City Disaster Management Plan2025 cited in its VLR. Public aggregate DALA statistics cannot replace these observations.

## MMS: rainfall

Request Male AWS/local-island gauges if available plus nearby Hulhule observations, matching the selected event dates. Ask for hourly data and any available10/15-minute measurements, original accumulation windows, time convention (UTC or Maldives UTC+5), station coordinates/instrument history, QC flags, missing-data codes and permissions for derived publication. Suggested starting period2019-2026, to be adjusted to actual flood records and MMS availability. Do not request raw-data redistribution by default: MMS form restricts third-party redistribution without permission.

## Project/engineering custodian: local elevation and drains

Reference completed Male stormwater detailed designs/tender documents, reported completedMay2024 by the WorldBank; contract MV-MONPI-234588-CS-CQS appears in the2021 TOR. Request survey points/DEM if produced; vertical datum/accuracy; GIS/CAD existing and proposed drains; invert/ground elevations; inlets/outfalls; sizes/capacities; pump locations/capacities/operating logs; dated condition/maintenance and intervention records; hydraulic model inputs/outputs if sharable. Confirm installed versus design/proposed network. Distinguish this contract from cancelled2023 masterplan/DEM EOI MV-MONPI-326937-CS-QCBS.

## Honest fallback if access fails

Retain Male as the case study. Complete a reproducible exploratory data/feature map and a transparent data-gap assessment. Train a predictive model only if defensible observations and evaluation groups exist. An expert-weighted susceptibility index or synthetic hydraulic labels must be identified as such and cannot be presented as validated observed street flooding.
